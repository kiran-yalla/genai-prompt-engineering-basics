# Zero-Shot Prompting Examples

Zero-shot prompting asks the model to perform a task directly, without giving it any examples first.

## Example 1 - Summarization

```
Prompt: Summarize the following paragraph in one sentence:
"Cloud migration involves moving applications, data, and infrastructure from on-premises
data centers to cloud providers like AWS. It requires careful planning around cost,
security, and downtime to ensure a smooth transition."
```

## Example 2 - Classification

```
Prompt: Classify the sentiment of this sentence as Positive, Negative, or Neutral:
"The deployment finished without any errors."
```

## Example 3 - Explanation

```
Prompt: Explain what a VPC is, in simple terms, for someone new to AWS.
```

## When to Use Zero-Shot

Zero-shot prompting works well for simple, well-understood tasks where the model likely already has strong prior knowledge (e.g., general summarization, common classification tasks, factual explanations).
