# Role-Based Prompting Examples

Role prompting asks the model to respond as if it were a specific persona or expert, which helps shape tone, vocabulary, and focus.

## Example 1 - Senior Engineer Persona

```
Prompt: You are a senior DevOps engineer mentoring a junior teammate.
Explain, in a friendly and encouraging tone, why we use Infrastructure as Code
instead of manually configuring servers.
```

## Example 2 - Reviewer Persona

```
Prompt: You are a strict code reviewer focused on security. Review the following
script and list any security concerns you notice.
```

## Example 3 - Simplifier Persona

```
Prompt: You are a teacher explaining technical topics to complete beginners.
Explain what an API is using a simple real-world analogy.
```

## Why Role Prompting Helps

Assigning a role narrows the model's tone and level of detail, and can help produce output that is better suited to the intended audience (e.g., beginner-friendly vs. expert-level).
